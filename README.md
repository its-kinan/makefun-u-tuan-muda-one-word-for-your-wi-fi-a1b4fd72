One word for your Wi-Fi: **Ghosting**. Home Wi-Fi ghosts you — full bars one second, gone mid-sentence the next. It reads your message, shows up when it feels like it, and vanishes the moment you actually need it. A relationship word for a relationship problem, and it works as a network name.

## Run it

```sh
node main.ts
```

Writes the single word to `/output/entry.txt` (deterministic: no network, no clock, no randomness).
